# 📱 दैनिक आय-व्यय प्रबंधक (Smart Khata) - Android APK Build Guide

यह ऐप आपके दैनिक खर्च और आय को व्यवस्थित रखने के लिए एक सुरक्षित, आधुनिक और 100% प्राइवेट डिजिटल बहीखाता है।

---

## ⚡ GitHub से 3 मिनट में APK बनाकर फोन में कैसे डाउनलोड करें:

### स्टेप 1: GitHub पर नया Repository बनाएं
1. [GitHub.com](https://github.com) पर जाएं और लॉगिन करें।
2. **"New Repository"** पर क्लिक करें।
3. नाम दें: `smart-khata` और इसे **Public** रखें।
4. **"Create repository"** पर क्लिक करें।

### स्टेप 2: यह सारी फाइल्स GitHub पर अपलोड करें
1. GitHub पेज पर **"uploading an existing file"** पर क्लिक करें।
2. इस ज़िप फाइल (ZIP) के अंदर की सभी फाइल्स और फोल्डर (`index.html`, `manifest.json`, `package.json`, `.github/` फोल्डर) को खींचकर (drag & drop) अपलोड कर दें।
3. नीचे हरा बटन **"Commit changes"** दबाएं।

### स्टेप 3: GitHub Actions अपने आप APK बनाएगा
1. अपलोड होते ही GitHub के ऊपर दिए गए **"Actions"** टैब पर क्लिक करें।
2. आपको **"Build Android APK"** नाम का प्रोसेस चलता हुआ दिखेगा (पीला घेरा घूमेगा)।
3. लगभग 2 से 3 मिनट में यह हरा टिक (Success) हो जाएगा।

### स्टेप 4: फोन में APK डाउनलोड करें
1. उस पूरे हुए प्रोसेस (Workflow Run) पर क्लिक करें।
2. नीचे **"Artifacts"** सेक्शन में आपको **`SmartKhata-Android-APK`** फाइल मिलेगी।
3. उस पर क्लिक करके सीधे अपने फोन में डाउनलोड करें और इंस्टॉल करें!

---

## 🚀 वैकल्पिक आसान तरीका (बिना APK, 10 सेकंड में फोन में इंस्टॉल करें):
1. GitHub Repository की **Settings > Pages** में जाएं।
2. Source में `main` branch चुनकर **Save** करें।
3. GitHub आपको एक लिंक देगा (जैसे: `https://yourname.github.io/smart-khata/`)।
4. इस लिंक को अपने मोबाइल के **Chrome Browser** में खोलें।
5. Chrome के 3-डॉट्स (Menu) पर जाएं और **"Add to Home Screen" (होम स्क्रीन पर जोड़ें)** दबाएं।
6. ऐप बिना किसी APK झंझट के तुरंत आपके मोबाइल की स्क्रीन पर ऐप आइकन के रूप में आ जाएगा और 100% ऑफलाइन काम करेगा!

## 🌟 इस ऐप की मुख्य विशेषताएं:
- **कोई पूर्व-निर्धारित श्रेणी नहीं:** अपनी इच्छानुसार स्वयं श्रेणियां जोड़ें व हटाएं।
- **खर्च व आय ट्रैकिंग:** नकद, UPI, बैंक, कार्ड आदि के साथ।
- **मासिक बजट लक्ष्य:** खर्च की सीमा तय करें और 80%/100% पर अलर्ट पाएं।
- **WhatsApp रिपोर्ट शेयरिंग:** एक क्लिक में बहीखाते का संपूर्ण विवरण व्हाट्सएप पर भेजें।
- **Excel (CSV) एक्सपोर्ट:** अकाउंटिंग के लिए तुरंत एक्सेल शीट डाउनलोड करें।
- **विश्लेषणात्मक ग्राफ:** पाई/डोनट चार्ट और मासिक तुलना बार चार्ट।
- **100% ऑफलाइन एवं प्राइवेट:** आपका डेटा किसी सर्वर पर नहीं जाता, सिर्फ आपके फोन में सुरक्षित रहता है।
- **बैकअप एवं रीस्टोर:** कभी भी बैकअप JSON फाइल डाउनलोड या रीस्टोर करें।
